# Content roadmap

Rule for every new page: one clear search need, one audience, one canonical URL, a direct answer in the first 60 words, original value (Robin's experience, a diagram, a tool or an audio example), 2–3 sideways links, one link up to a money page. If a topic can't clear that bar, don't publish it.

**Byline rule:** new guides carry "By the Pianoforall team" until Robin has read them. Once he has reviewed and edited a guide, switch `author` to `"Robin Hall"`, which adds his name and photo and points the Article schema at his Person entity.
