How to use this
  1. Do Start here first: the theme upload and the one setting take five minutes and fix the affiliate tagging on every page.
  2. Then open a post below, open the same post in Ghost Admin in another tab, and work down its list. Every value has a Copy button.
  3. For a sentence to correct, use your browser's find (Ctrl/Cmd + F) in the Ghost editor with the red "Find" text, then paste the green text over it.
  4. Tick each task when it's done, then click Update in Ghost.
