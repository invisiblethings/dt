## How to publish
1. **Images:** upload the 13 inline images in `images/` (everything except the featured and social images) in **October 2026**. If you upload in November, find and replace `2026/10` with `2026/11` in `article.html`.
2. **PDF:** add a File card, upload `30-day-piano-challenge.pdf` in October 2026, then delete the card. The download box links to `/content/files/2026/10/30-day-piano-challenge.pdf`. If Ghost renames the file, paste the real address into that link.
3. **Article:** replace the old body with one **HTML card** containing all of `article.html`. The interactive tools' style and script are at the end of that same card.
4. **Fields:** set the fields above, then update the post. Request indexing in Search Console.
5. **Check on the live page:**
