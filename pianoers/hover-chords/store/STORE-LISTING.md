# Chrome Web Store listing

**Name:** Hover Chords: Piano Chord Finder

**Summary (132 characters max):**
Hover any chord on a chord sheet to see it on a piano keyboard. Hear it, try inversions and transpose the whole song.

**Category:** Education (or Entertainment)

**Language:** English

## Description
See every chord on a piano keyboard, right where you read it.

Chord sheets are written for guitarists. When you're at the piano, "F#m7b5" or "D/F#" means stopping to look it up. Hover Chords fixes that: hover any chord on a chord sheet and a small keyboard shows exactly which keys to play.

WHAT IT DOES
• Hover a chord to see it on a piano keyboard, with the note names
• Click to pin it and hear it played
• Step through inversions (root position, 1st, 2nd, 3rd)
• Transpose every chord on the page up or down with one click
• Slash chords show the bass note in its own colour
• Notes are spelled correctly for the chord (C7 shows Bb, not A#)

WORKS WITH
Chord sheets on chord websites, song sheets, worship sets, tabs, and ChordPro text like [C]Let it [G]be. It understands majors, minors, 7ths, maj7, dim, half-diminished, aug, sus, 6, 9, 11, 13, add9, altered chords, power chords and slash chords.

PRIVATE BY DESIGN
• No account, no tracking, no data collected
• Works offline; sound is made in your browser
• Turn it off for any website, or everywhere, from the toolbar

Made by Pianoers.com, a piano teaching site with free lessons and guides for adult learners.

## Permission reasons (for the review form)
- **storage:** saves your settings (on/off per site, transpose amount, sound) on your computer.
- **activeTab:** lets the toolbar popup show which website you're on, so you can switch Hover Chords on or off for that site.
- **Content script on http/https pages:** chord sheets can be on any website, so the script checks the page text for chord names. It only changes the page when it finds a chord sheet, and it never sends page content anywhere.

**Single purpose:** shows the chords on the page you're reading as piano keyboard diagrams.
